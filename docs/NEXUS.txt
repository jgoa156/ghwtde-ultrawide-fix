Short description: Basically the game finds the closest 16:9 to your resolution if in a ultrawide resolution and renders the HUD elements/interface in that resolution, while adjusting to the ultrawide resolution (left aligned menus, for example). Since 1.1 the gameplay is no longer zoomed in, and it works without ReShade.

Full description:

Description
On ultrawide screens (2560x1080, 3440x1440 and similar), Guitar Hero World Tour: Definitive Edition stretches its whole 2D layer sideways (HUD, menus and text) and zooms the gameplay in: it cuts the picture at the top and bottom, so the highway runs off the bottom of the screen and no longer lines up with the HUD. This mod draws the 2D layer at the closest 16:9 size, centred and unstretched (for example 1920x1080 inside 2560x1080), and gives the 3D scene (venue, band, highway) 16:9's vertical view, so it shows more at the sides instead of zooming in. Since 1.1 it is an ASI plugin, not a ReShade add-on: it works with any ReShade preset, GShade, DXVK, or no ReShade at all.
Installation instructions

1. Open the folder that has GHWT_Definitive.exe.
2. Copy ghwtde_ultrawide.asi and ghwtde_ultrawide.ini into it.
3. If you don't have a dinput8.dll there yet, also copy the one from the "ASI Loader (only if you do not have it)" folder in the zip.
4. Updating from 1.0: delete ghwtde_ultrawide.addon32 from the game folder.
5. Start the game. ghwtde_ultrawide.log, next to the game exe, shows what the plugin hooked.

To uninstall, delete ghwtde_ultrawide.asi and ghwtde_ultrawide.ini, plus dinput8.dll if you only added it for this mod.
Main features

* The gameplay is no longer zoomed in: the 3D scene keeps 16:9's vertical view and shows more at the sides; the highway is the same size as on a 16:9 screen and lines up with the HUD again (new in 1.1).
* The HUD, menus and text are drawn as a centred 16:9 picture, unstretched.
* Full-screen backgrounds fill the screen without distortion: the title screen wall, song list side art and every YOU ROCK theme.
* Gradients and dimmers stretch to the full width.
* Side panels (Career / Quickplay mode select, instrument select, the song intro) are pinned to the left edge of the screen.
* Loading screens are shown as 16:9 with black side bars. One setting (LoadingFill) makes them fill the width instead.
* It does nothing at 16:9 or narrower.
* Every rule can be changed in ghwtde_ultrawide.ini (HorPlus=0 brings back the game's zoomed 3D view).

Requirements

* Guitar Hero World Tour: Definitive Edition.
* An ASI loader (dinput8.dll). A copy is included in the download.
